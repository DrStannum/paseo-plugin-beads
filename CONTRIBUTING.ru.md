# Как участвовать

[English](CONTRIBUTING.md) · **Русский**

Спасибо за интерес. Это маленький плагин с одной задачей, поэтому планка тут не
столько про процесс, сколько про то, чтобы не сломать то, что он обещает: чтение
никогда не пишет, плагин никогда не удаляет и не коммитит, а панель никогда не
превращает недоверенный текст в разметку.

## Прежде чем начать

- **Исправления ошибок** — сразу присылайте pull request.
- **Новое поведение** — сначала заведите issue. Панель намеренно узкая (она
  смотрит, создаёт и правит задачи beads; она не удаляет их, не коммитит и не
  управляет git), и обсудить рамки до написания кода — бережнее для всех.
- **Вопросы** — issue вполне подойдёт; отдельного форума нет.

## Как всё поднять

```bash
git clone https://github.com/DrStannum/paseo-plugin-beads.git
cd paseo-plugin-beads
npm install
paseo plugin install .
```

Нужны Paseo 0.15.4 или новее с запущенным демоном, Node 22.18 или новее и
[beads](https://github.com/gastownhall/beads) (`bd`) в `PATH`. После изменения
`paseo plugin reload beads` пересобирает плагин; перезапускать демон не нужно.
Подробности — в [Разработке и тестах](docs/ru/development.md).

## Тесты

```bash
npm test            # typecheck + все tests/*.test.ts
npm run smoke       # только RPC-обработчики против заглушки bd, за секунды
npm run preview     # все скриншоты в настоящем веб-приложении Paseo, около 20 минут
```

**Если вы поменяли интерфейс, переснимите затронутые скриншоты, посмотрите на них и
закоммитьте PNG** — они одновременно иллюстрации документации
([docs/ru/screenshots.md](docs/ru/screenshots.md)) и фикстуры против регрессий.
Скриншоты рисуются на синтетической фикстуре из `tests/fixture/` и никогда на
настоящем проекте: текст задач может нести секреты.

## Что изменение обязано соблюсти

Это инварианты, ради которых существуют тесты. Pull request, которому нужно нарушить
один из них, должен сказать об этом вслух.

- **Чтение и запись остаются раздельными.** Каждый читающий вызов несёт
  `--readonly`; запускать пишущую подкоманду могут только `beads.edit`,
  `beads.create`, `beads.comment`, `beads.export` и `beads.sync`, и набор пишущих
  подкоманд закрыт (`create`/`update`/`close`/`reopen`/`export`/`import`/`comment`).
  `delete` в него не входит, и добавлять его не надо.
- **Никаких git-коммитов, никогда.** Плагин не выполняет `git add`/`git commit` и
  никогда не включает Dolt auto-commit.
- **Рабочее пространство определяет демон.** RPC принимают id рабочего
  пространства, а не путь.
- **Никакой сырой разметки из данных.** Никаких `dangerouslySetInnerHTML`,
  `innerHTML` или `eval` с текстом задач: Markdown разбирается в дерево и рисуется
  компонентами. Ссылки ограничены `http(s)`, `mailto` и относительными путями.
  Сторож здесь — `tests/markdown.test.ts`; дополняйте его, когда трогаете
  отрисовщик.
- **Никаких зависимостей в рантайме.** Только то, что даёт хост Paseo (`react`,
  `react-native`, `@tanstack/react-query`, `zod`, `@getpaseo/plugin`), и `node:*` на
  сервере.
- **Клиентский код, безопасный для Hermes.** Никаких `class`, `toSorted`, lookbehind
  в регулярных выражениях или флага `v`, никакого `Intl.Segmenter`.
- **Оба языка.** Новой видимой строке нужны и `en`, и `ru`
  (`client/i18n/strings.ts`). То же и с документацией: английская версия — источник
  истины, а лежащая рядом русская (`*.ru.md`, `docs/ru/`) обновляется тем же
  коммитом.
- **Логи без текста задач.** Диагностика печатает коды, счётчики и команды без
  пользовательских аргументов — никогда заголовки, тексты или комментарии.

## Коммиты и pull request'ы

Сообщения коммитов следуют [Conventional Commits](https://www.conventionalcommits.org/):
`feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`, с `!` для ломающего
изменения. Тема — в повелительном наклонении и короче ~72 символов; *почему*
объясняйте в теле.

Pull request должен:

- делать одну вещь и объяснять в описании, что и зачем;
- оставлять `npm test` зелёным;
- содержать пересъёмку скриншотов для всего, что видно глазами.
