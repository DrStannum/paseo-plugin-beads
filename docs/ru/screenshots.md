# Скриншоты

[English](../screenshots.md) · **Русский**

Каждая картинка здесь — артефакт тестов: `npm run preview` открывает настоящее веб-приложение
Paseo против локального демона, на время прогона регистрирует синтетическую
фикстуру из `tests/fixture/` как воркспейс и фотографирует панель, так что ничего
на этой странице не взято из живого проекта. Часы страницы остановлены на
фиксированном моменте, а настройки плагина держатся на значениях по умолчанию,
поэтому повторный прогон меняет только снимки того, что действительно изменилось.
Несколько прогонов заодно проверяют поведение, которое картинка показать не может, —
см. [Разработка и тесты](development.md). Каждый PNG, который рисует прогон, есть на
этой странице, и набор тестов следит, чтобы так и оставалось.
